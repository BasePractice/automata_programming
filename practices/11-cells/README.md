# 11-cells — клеточные автоматы

Практика к лекции 11. Три автомата в одном исполняемом файле; все утверждения
лекции о них проверяются тестами, а не принимаются на слово.

| Автомат | Что показывает |
|---|---|
| элементарный (Вольфрам) | правило — число 0..255; правило 90 даёт треугольник Серпинского, правило 110 полно по Тьюрингу |
| игра «Жизнь» | 52 фигуры: 25 из лекции (натюрморты, осцилляторы, корабли, ружьё Госпера, чеширский кот, «Сад Эдема») и 27 из LifeWiki и коллекции Golly |
| правило чётности | другое правило на том же поле: любая фигура размножается (Фредкин) |
| муравей Лэнгтона | два правила, хаос на 10 000 шагов и внезапное периодическое «шоссе» |
| умный муравей | автомат не задан, а ищется: каноническая тропа Санта-Фе и четыре стратегии |

## Запуск

```bash
11-cells rule 90 33 12       # треугольник Серпинского
11-cells rule 110 33 12      # узор правила 110
11-cells life glider 4       # глайдер: четыре поколения
11-cells life r-pentomino 50 # долгая эволюция пяти клеток
11-cells ant 11000           # муравей Лэнгтона: беспорядок и шоссе
11-cells trail scan          # умный муравей: тропа Санта-Фе за 315 тактов
11-cells trail evolved       # автомат, найденный поиском: 181 такт
11-cells patterns            # список фигур «Жизни»
```

## Терминальная «Жизнь»

`11-cells-life-tui` — интерактивная игра «Жизнь» в терминале. Цель
необязательная: режим терминала задаётся через termios, а это POSIX, не
ISO C90, и на Windows его нет. Внешних библиотек не нужно, только
эмулятор терминала с UTF-8.

```bash
cmake -S . -B build -DSTATECRAFT_BUILD_TUI=ON
cmake --build build --target 11-cells-life-tui
./build/practices/11-cells/11-cells-life-tui
```

| Клавиша | Действие |
|---|---|
| `r` | случайная расстановка, 30 % живых клеток |
| `p` (или пробел) | пауза и пуск |
| `→` / `←` | шаг вперёд / шаг назад (шаг останавливает прогон) |
| `↑` / `↓` | клетка крупнее / мельче, наименьшая — один пиксель |
| `o` | каталог готовых объектов: `↑↓`, `PgUp`/`PgDn`, `Enter` — поставить, `Esc` — назад |
| `q` | выход |

Пиксель — половина знакоместа: в знакоместе два квадратных пикселя,
верхний и нижний (символы `▀ ▄ █`). Поле равно окну и замкнуто в тор:
что ушло за правый край, появляется слева. Поэтому размер поля задаёт
крупность клетки. При её смене содержимое остаётся по центру, края
срезаются или дополняются пустыми клетками. Поле не больше 256 × 256 клеток
(`LIFE_MAX_SIDE`).

Шаг назад в «Жизни» нельзя вычислить: у конфигурации бывает много
предшественников, а у «Сада Эдема» нет ни одного. Поэтому программа
помнит последние 128 поколений. При смене размера поля история
сбрасывается, потому что на поле другого размера работает другой автомат.

В каталоге 54 объекта. Объекты лекции:

- тримино по правилу чётности Фредкина (размножается) и в «Жизни»
  (становится блоком);
- пять триплетов;
- чеширский кот;
- вирус в агаре: у грани блока он разрушает агар, в углу агар его
  залечивает;
- «Сад Эдема»;
- пожиратель и планер;
- остальные фигуры лекции 11.

Из LifeWiki и коллекции Golly:

- медленные корабли: медная голова c/10, бездельник c/7;
- ружьё Саймкина;
- пыхтящий поезд;
- челнок пчелиной матки, галактика Кока и другие осцилляторы;
- фигуры бесконечного роста, в том числе 20-клеточный рекорд квадратичного
  роста;
- гептамино;
- долгожители: «Кролики», «Лидка», «Ивона» и другие.

Если окно мало для объекта, клетка уменьшается сама, пока объект не
поместится.

Программа ничего не решает сама. Поле, история и каталог живут в
`life_session.[ch]`, и каждое действие клавиши проверяется тестом
(`life_session_tests.cpp`): возврат назад, сохранение центра при смене
размера, постановка каждого объекта каталога, поведение объектов лекции. Без
терминала программа выходит с сообщением, а не портит вывод
управляющими последовательностями. Это тоже тест `ctest`.

Фигуры из LifeWiki проверены так же, как фигуры лекции: тест сверяет
наименьший период осцилляторов, скорость кораблей, выпуск планеров ружьём и
число клеток с описанием в источнике. Фигуры, взятые из коллекции Golly,
перенесены из её RLE-файлов. Остальные записаны по каталогу LifeWiki и
приняты только после прогона. Thunderbird его не прошёл и в каталог не
попал.

## Векторные картинки для лекции

Иллюстрации лекции 11 порождает та же программа, которая считает автоматы, —
рисунок не может разойтись с моделью, потому что берётся из неё. Формат — SVG
без внешних зависимостей.

```bash
11-cells svg life glider 0,1,2,3,4 glider.svg      # лента поколений фигуры
11-cells svg life gosper-gun 0,30,60,90 gun.svg 56 # с указанием стороны поля
11-cells svg scene eater-vs-glider 0,4,8,12 eat.svg
11-cells svg scene agar-virus 0,4,10,20 agar.svg   # агар и «вирус»
11-cells svg parity tromino 0,1,2,4 parity.svg 40  # размножение по правилу чётности
11-cells svg langton 200,2000,7000,11000 ant.svg 96
11-cells svg trail scan 0,80,180,315 trail.svg     # прогон муравья по тропе
11-cells svg fsm scan fsm.svg                      # диаграмма автомата
11-cells svg fsm 3.0.0.1:3.0.0.2:3.0.0.3:3.0.0.4:3.0.2.0 fsm.svg
11-cells svg rule 90 41 20 rule90.svg
```

Весь набор картинок лекции перерисовывается одной командой:

```bash
practices/11-cells/render-figures.sh
```

Подписей внутри картинок нет намеренно: надписи в лекциях курса набираются
чертёжным шрифтом по ГОСТ 2.304-81 средствами typst, а SVG вставляется как
изображение. Исключение — диаграмма автомата: там надписи неотделимы от
рисунка, и шрифт запрашивается тот же (`osifont`).

Вывод текстовый: `#` — живая клетка, `.` — пустая, `@` — муравей. У тропы
муравья `#` — еда, `o` — съеденная клетка, `.` — клетка тропы без еды.

## Умный муравей: тропа и стратегии

Тропа — каноническая **Санта-Фе**: 89 клеток еды на торе 32 × 32, лимит 600
тактов, старт в левом верхнем углу лицом на восток. Карта перенесена из
репозитория [c_fsm](https://github.com/BasePractice/c_fsm); она же используется
в работах по генетическому программированию, поэтому числа тактов отсюда
сравнимы с опубликованными.

| Стратегия | Состояний | Результат | Что делает |
|---|---|---|---|
| `lookaround` | 4 | 42 из 89 | осмотр вправо-влево, без слепых шагов |
| `probe` | 6 | 59 из 89 | осмотр вправо-влево плюс два шага вслепую |
| `scan` | 5 | 89 из 89 за 315 тактов | осмотр всех четырёх направлений, затем шаг вслепую |
| `evolved` | 17 | 89 из 89 за 181 такт | найден поиском, см. практику `11-ant-search` |

`probe` разбирался как эталон, пока тропа была учебной и регулярной; на
Санта-Фе он встаёт. Это не дефект стратегии, а показательный случай: правило
поведения, подогнанное под знакомую карту, на канонической не работает, и
обнаруживается это только прогоном.

Автомат можно задать и таблицей прямо в командной строке — в том же формате,
в каком его печатает поиск:

```bash
11-cells trail 3.0.0.1:3.0.0.2:3.0.0.3:3.0.0.4:3.0.2.0
```

Четыре числа на состояние: действие при еде, переход при еде, действие без
еды, переход без еды. Действия: `0` — направо, `1` — налево, `2` — шаг, `3` —
шаг со съеданием (у нас шаг съедает всегда, поэтому `2` и `3` при разборе
неразличимы; формат сохранён ради сравнимости с опубликованными таблицами).

## Что здесь существенно

**Двойной буфер обязателен.** Новое состояние поля считается по старому
целиком: если обновлять клетки по мере обхода, соседи справа и снизу увидят
уже новые значения — получится другой автомат с правдоподобной, но неверной
картинкой. Это прямое следствие определения глобальной функции переходов.

**Фигуры из книг проверяются прогоном.** Конфигурации чеширского кота, «Сада
Эдема» и агара считаны со сканов книги М. Гарднера, лежавших в лекции. Каждая
проверена тем, что о ней сказано в источнике: кот оставляет «улыбку» на шестом
ходу и блок на седьмом, у «Сада Эдема» 226 клеток в прямоугольнике 33 × 9,
агар восстанавливается после вируса в углу блоков и разрушается от вируса у
грани. Фигура, взятая из литературы и не проверенная прогоном, рано или поздно
оказывается записанной с ошибкой — так было с пентадекатлоном, который в
книгах рисуют рядом из десяти клеток, а это не фаза осциллятора, а его предок.

**Край поля — не деталь реализации.** У одномерного автомата и «Жизни» поле
замкнуто в кольцо и тор: так у картинки нет выделенных точек. У муравья
замыкать нельзя — его «шоссе» уходит в бесконечность и на торе замкнулось бы
само на себя, дав поведение, которого у настоящего муравья нет. Поэтому
`ant_step` возвращает `false`, когда муравей упирается в край.

## Тесты

| Утверждение лекции | Как проверяется |
|---|---|
| правило 90 строит треугольник Серпинского | первые ряды сравниваются посимвольно |
| правило 0 гасит поле, 255 заливает | состояние после одного шага |
| мигалка имеет период 2 | конфигурация совпадает через два хода |
| блок устойчив | конфигурация не меняется пять ходов |
| глайдер движется со скоростью `c/4` | через 4 хода — сдвиг на (1, 1) |
| LWSS движется со скоростью `c/2` | через 4 хода — сдвиг на 2 клетки |
| муравей Лэнгтона строит шоссе | после 10 500 шагов смещение за 104 шага постоянно |
| тропа каноническая | на карте ровно 89 клеток еды |
| `scan` проходит тропу | 89 из 89 ровно за 315 тактов |
| `evolved` проходит тропу быстрее | 89 из 89 ровно за 181 такт, 17 состояний |
| `probe` на Санта-Фе не хватает | съедено ровно 59 из 89, прогон не завершён |
| `lookaround` не хватает тем более | съедено ровно 42 из 89 |
| запись автомата разбирается и печатается | `scan` ↔ `3.0.0.1:3.0.0.2:3.0.0.3:3.0.0.4:3.0.2.0` |
| натюрморты не меняются | блок, улей, каравай, лодка, ванна, пожиратель — четыре хода без изменений |
| осцилляторы имеют период | мигалка и жаба — 2, маяк — 2, пульсар — 3, пентадекатлон — 15 |
| MWSS и HWSS идут со скоростью `c/2` | через 4 хода — сдвиг на 2 клетки |
| ружьё Госпера растёт неограниченно | +5 клеток за каждые 30 поколений |
| `diehard` живёт 130 поколений | и вымирает без следа |
| каждое имя из списка фигур ставится | список и таблица фигур не разъезжаются |
| ленты SVG строятся | число рамок равно числу кадров, глайдер — 5 клеток на кадр |
| чеширский кот исчезает по книге | на 6-м ходу «улыбка» из 4 клеток, на 7-м — блок |
| «Сад Эдема» перенесён верно | 226 клеток в прямоугольнике 33 × 9 |
| пять триплетов ведут себя по книге | три погибают за 3 хода, тримино даёт блок |
| агар устойчив, вирус решает всё | в углу блоков агар восстанавливается за 2 хода, у грани — разрушение растёт |
| правило чётности размножает тримино | на 4-м ходу — ровно 4 копии, 12 клеток |
